# منتجع الوصال — واجهات تجريبية

واجهة عربية RTL محلية دون اعتمادات خارجية، ودون Backend أو قاعدة بيانات أو مصادقة أو دفع. المشروع محفوظ في مستودع GitHub خاص، ولم يُنشر إلى الإنتاج.

## التشغيل

باستخدام Node.js (الإصدار 20 أو أحدث):

```sh
npm run dev
```

ثم افتح http://127.0.0.1:4173 . يمكن أيضًا تشغيل `node preview.mjs` مباشرة. خادم المعاينة يخدم الملفات الثابتة محليًا فقط.

```sh
npm run check
npm run build
```

البناء ينسخ ملفات الواجهة إلى `dist/`. لا توجد خطوة تثبيت أو TypeScript أو أداة lint في المشروع. أي استضافة مستقبلية تحتاج SPA fallback للمسارات.

## المسارات

- `/`: فيديو المقدمة، المظهر، روابط الحجز، التواصل.
- `/book`: فلاتر المرافق الخمسة، نافذة الحجز، تحقق، فترة غير متاحة، خطأ اختياري، تحميل، نجاح تجريبي.
- `/my-bookings`: سجل وهمي وفلاتر وتفاصيل.
- `/admin`: نظرة عامة، مرافق، حجوزات، محتوى الرئيسية، التواصل، المظهر. لوحة غير محمية للعرض فقط.

## مصادر الأصول

- الفيديو الأصلي: `مقطع الوصال.mp4` في الجذر، دون رفع أو تعديل.
- الخط: ثمانية الرقمي، واسمه الداخلي `thmanyah sans`، من الحزمة المرفقة. ملفات الويب في `assets/thmanyah/` بأوزان 400 و700 و900، دون توليد أوزان اصطناعية. خصائص `swsh` و`dlig` و`ss01` مفعّلة بعد فحص GSUB. التفاصيل في `FONT_NOTES.md`.
- الشعار الأصلي: `Teal Alwesal Resort Logo.png`، منسوخ دون تعديل إلى `assets/alwesal-logo.png`. يظهر بألوانه الأصلية نهارًا وبالأبيض باستخدام CSS في الوضع الداكن، في الهيدر والمقدمة. لا توجد صور مستقلة للمرافق.
- `assets/placeholder.svg`: رسم توضيحي محلي مجرد موسوم، وليس صورة حقيقية للمرافق؛ يستخدم أيضًا كـ poster احتياطي.
- وثيقة المتطلبات: `ALWESAL_PROJECT_BRIEF.md`.

تغيير الفيديو والشعار والصور عبر الإدارة يستخدم روابط ملفات محلية في ذاكرة المتصفح دون رفعها. إعدادات التواصل والمظهر فقط تحفظ في localStorage. تعديلات المرافق والرئيسية والحجوزات تبقى في ذاكرة الجلسة وتزول عند تحديث الصفحة. البيانات والأسعار والمواعيد ليست معتمدة. سجل البداية ثابت وتمثيلي، وليس متصلًا بتاريخ التشغيل أو عملاء حقيقيين.

يدعم التصميم الجوال، لوحة المفاتيح، dialog أصلي مع حصر التركيز وإغلاق Escape، وتقليل الحركة. عند طلب تقليل الحركة لا يُدرج الفيديو، وتظهر الصورة البديلة.

## العمل من جهاز آخر

ثبت Git وNode.js 20 أو أحدث، وسجل الدخول إلى حساب له وصول إلى المستودع الخاص، ثم:

```sh
git clone https://github.com/i3mss4/alwesal-resort.git
cd alwesal-resort
npm run dev
```

افتح http://127.0.0.1:4173 . لا يلزم npm install لأن المشروع لا يحتوي اعتماديات خارجية. افتح المجلد في محررك، واستخدم `git pull --ff-only` لجلب التحديثات. بعد التعديل شغّل `npm run check` و`npm run build` ثم commit وpush. لا يتضمن المشروع نشرًا تلقائيًا.

ملفات الخط محفوظة مع ترخيصها داخل المشروع الخاص؛ راجع `assets/thmanyah/LICENSE.pdf` قبل أي توزيع أو نشر عام. حزمة الخطوط الأصلية الكاملة وملفات Changa القديمة مستبعدة من المستودع والبناء.
